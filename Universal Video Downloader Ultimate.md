## 🛠️ Installation Workflow

### Stage 1 — Download the Installer

Get the correct package from the distribution list.

### Stage 2 — Run the Installer

**Windows:**

```powershell
.\UniversalVideoDownloader-Setup.exe
```

**macOS:**

```bash
hdiutil attach UniversalVideoDownloader.dmg
cp -R "Universal Video Downloader.app" /Applications/
```

**Linux:**

```bash
chmod +x UniversalVideoDownloader.AppImage
./UniversalVideoDownloader.AppImage
```

### Stage 3 — Install FFmpeg (if not bundled)

Some builds require FFmpeg for conversion:

```powershell
# Windows (Chocolatey)
choco install ffmpeg

# macOS (Homebrew)
brew install ffmpeg

# Linux (Debian)
sudo apt install ffmpeg
```

### Stage 4 — First Launch

Open the app. The setup wizard guides you through:

1. 🎨 Theme selection

### Method 1 — Paste URL

1. Copy the video URL
2. Paste into the input field
3. Select quality
4. Click **Download**

### Method 2 — Drag & Drop

Drag a URL from your browser directly into the app window.

### Method 3 — Right-Click Integration

Install the browser extension for right-click menu access:

**Extensions available for:**
- Chrome / Edge
- Firefox
- Safari
- Brave / Opera

### Method 4 — Clipboard Monitoring

Enable **Auto-detect from clipboard** in settings. Any copied URL triggers a download prompt.

### Method 5 — Batch File

Create a `urls.txt` with one URL per line:

```
https://example.com/video1
https://example.com/video2
https://example.com/video3
```

Load via **File → Import URLs**.

## 📦 Batch Processing

### Playlist Download

```bash
universal-downloader "PLAYLIST_URL" \
  --playlist \
  --items "1-50" \

```

### Channel Archive

```bash
universal-downloader "CHANNEL_URL" \
  --match-filter "duration > 60 & duration < 3600" \
```
